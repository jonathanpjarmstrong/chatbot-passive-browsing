Key Design Moves

Entry
Mood chips replace the blank field
Users pick from visible options (recognition memory) instead of generating a query from nothing (recall memory). Cognitive load drops immediately.
Flow
No commitment before browsing
Pickup time, delivery address, payment: all deferred to checkout. The menu is free to explore without an "order session."
Trails
Every response opens 3 paths
Deeper (more burgers), lateral (under $10), or up (all categories). The user forages without typing a new search.
Fallback
Active search is still available
The text input exists for users who know what they want. Passive browsing is added, not replacing the active path.
